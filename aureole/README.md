# AUREOLE · Orbit 动效网页复刻

复刻一段 32 秒的 UI 动效演示视频（品牌名 Orbit）。整段动画由**一条时间轴**驱动，同时保留真实交互。三套色系可切换。

**直接打开 `aureole/index.html` 即可**：单文件，字体、样式、脚本全部内联，离线可用。
GitHub Pages 副本：`docs/aureole/index.html`（站点 `/aureole/`）。

## 六幕内容（对应视频）

| # | 场景 | 视频里的动效 | 网页里可以做什么 |
|---|------|-------------|-----------------|
| 1 | **Level** | 彗星坠落成玻璃方块，沿点阵轨道滑行，标题 Idea → Task → Mission → Goal 逐词翻转 | 拖动方块 |
| 2 | **Priority** | 玻璃圆球在点阵卡片上移动，周围点阵按距离发光，右下角有"建议位置"圆环 | 在卡片上拖动圆球，标签随象限变化（Do first / Plan / Quick / Later） |
| 3 | **Capture** | "Good evening." 输入卡，点麦克风录音，点阵声波，逐词模糊浮现，完成后镜头拉远，发送键化为光点 | 点麦克风 / 停止 / 发送 |
| 4 | **Task** | 光点落成胶囊，展开成任务卡，倒计时数字乱码滚动，点勾完成：镜头推进、划线、进度拉满、"Done → Deck finished → 1h 02m early → Nice work." | 点 ✓，或把滑块拖到最右 |
| 5 | **Completed** | 热力图自右向左逐格出现，统计数字滚动计数，最后一格变成光点飞走 | 悬停任意一格查看当天任务数 |
| 6 | **Welcome** | 光点逐字写出 "Welcome to Orbit."，灰色像素点阵烟雾升起，"COMING SOON" | 指针靠近会让烟雾变亮 |

彗星是场景之间的转场：上一幕的主体收缩成光点，拖着尾迹飞到下一幕的落点。

## 三套色系

底色始终是纯黑，只换点缀色。按键 `1` `2` `3`，或用底部控制栏。默认是 **Loyel 渐变蓝**，选择会记在浏览器里。

| 色系 | 来源 | 色值 |
|------|------|------|
| **Orbit 原版** | 对视频逐帧取样 | 靛紫 `#4a3fe0` → 钴蓝 `#2e74e8` → 青 `#4cc3f5`；强调 `#9db6ff`；热力图 `#121214 #26344c #46557b #6682bd #87aef8` |
| **Loyel 渐变蓝** | 十档官方色值，不混入其他蓝 | `#F4F7FB #E8EEF6 #CCDBEB #9FBDDA #6C9AC4 #497DAE #376392 #2E5076 #2B4868 #263B54` |
| **极光绿** | 按 Loyel 的十档结构新设计 | `#F2FBF7 #E0F6EC #BDEBD6 #8DDDBA #5BCB9C #38B386 #279470 #1F7559 #1B5B48 #153F34`，另加青绿点缀 `#7FE5D3` |

色板定义在 `src/js/01-core.js` 的 `RAW`。切换时所有颜色（包括画布里的点阵）会在 0.75 秒内平滑过渡。

## 操作

- 底部控制栏：色系 · 章节（点击跳转，下划线是进度）· 播放/暂停 · 重播
- 键盘：`空格` 暂停　`←` `→` 上一幕/下一幕　`R` 重播　`1` `2` `3` 色系
- 抓住方块、圆球、滑块时时间轴会暂停，松手约 2.5 秒后继续
- 开启系统"减少动态效果"时，页面默认暂停在任务卡

## 实现

- **时间轴驱动**：每一幕是 `render(lt)`，由局部时间 `lt` 算出全部画面，所以可以随意跳转、暂停、拖动。交互只在特定变量上叠加"手动覆盖"，松手后平滑回到脚本。
- **玻璃 UI 用 DOM**（渐变描边、`backdrop-filter`），**点阵、声波、彗星、烟雾用 Canvas 2D**。
- 世界坐标按视口缩放（`k`），手机竖屏会自动减少轨道列数、收窄卡片。
- 字体：Montserrat（可变，latin 子集）与 Open Sans 600，均为 SIL OFL，已内联为 base64。

```
aureole/
├─ index.html        构建产物（单文件）
├─ build.mjs         node aureole/build.mjs
└─ src/
   ├─ style.css  body.html
   ├─ js/01-core.js     工具、三套色板、布局、文字切换器
   ├─ js/02-fx.js       彗星、光点、像素烟雾
   ├─ js/03-scenes.js   六个场景
   ├─ js/04-main.js     转场彗星、主循环、控制栏
   └─ fonts/
```

改完源码后运行 `node aureole/build.mjs`，会同时更新 `aureole/index.html` 和 `docs/aureole/index.html`。

## 与视频的差异

- 视频结尾写的是 "COMMING SOON"（拼写错误），这里改为 **COMING SOON**。
- 视频是固定镜头的录屏，这里每一幕居中排版，并按视口自适应。
- 时间轴约 38 秒（视频 32 秒），为了让每一步更容易看清。
