# Display fonts

Subset, overlap-merged copies (see `../tools/make_fonts.py`) of these Google Fonts,
taken from the `@fontsource/*` npm packages. All are licensed under the
SIL Open Font License 1.1 (https://openfontlicense.org).

| File | Family | Designer |
|------|--------|----------|
| Oswald-400/500/600.woff2 | Oswald | Vernon Adams, Kalapi Gajjar, Cyreal |
| BebasNeue-400.woff2 | Bebas Neue | Ryoichi Tsunekawa (Dharma Type) |
| Orbitron-600.woff2 | Orbitron | Matt McInerney |
| Michroma-400.woff2 | Michroma | Vernon Adams |
| Syncopate-700.woff2 | Syncopate | Astigmatic |

The page refers to them under renamed families ("Oswald Hollow" etc.), so they never
clash with an installed copy of the original fonts.
