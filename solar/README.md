# Particle Solar System · 粒子太阳系

一个随滚动变形的粒子网站：太阳与九大行星（地球带月球）全部由荧光粒子组成，滚动时粒子散成星尘旋涡，再聚合成下一个天体。配乐与音效在浏览器里实时合成。

- **直接打开 `solar/dist/index.html`**：单文件，three.js 和英文字体都已内嵌，双击即可离线运行（中文正文字体在线时用 Noto Sans SC，离线时用系统字体）。
- GitHub Pages 副本：`docs/solar/index.html`（Pages 使用 `/docs` 目录时，地址为 `…/claude/solar/`）。
- URL 参数 `?n=30000` 可调粒子数（默认电脑 60,000 / 手机 28,000）。

```bash
npm install
npm run build:solar    # 生成 solar/dist/index.html
npm run dev:solar      # 修改即重建，并在 http://localhost:8001 预览
```

## 2. 两种色态（右上角"多色 / 单色"，或按 <kbd>C</kbd>）

每个粒子同时携带两套颜色，切换时颜色以波浪形从屏幕一侧扫到另一侧，波前短暂增亮。

- **多色**：依据 NASA 真彩色影像为每个天体定色，例如：太阳白光盘面 + Hα 粉红日珥 + 珍珠色日冕；水星参照 MESSENGER 彩色图（蓝灰低反照率物质、棕褐平原）；金星奶油黄云顶；地球深蓝海洋、绿 / 黄褐陆地、白云；火星氧化铁红；木星奶油色带区与棕色带纹、橙红大红斑；土星奶油黄与蓝灰六边形；天王星淡青；海王星浅蔚蓝（按 2024 年真实色研究，不用旅行者号的高对比深蓝）；冥王星奶白心形与暗红克苏鲁区 + 蓝色雾霾；银河系暖黄核球、蓝白旋臂、粉色 HII 区。
- **单色**：所有行星使用 Loyel 渐变蓝色板（#E8EEF6 → #263B54）表现的低饱和蓝色荧光，明暗仍保留各自的地貌特征；太阳（以及首页的太阳、银河里的太阳标记）为橙色火焰色系。

## 3. 荧光强度与字体（右上角"设置"，或按 <kbd>S</kbd>）

| 设置 | 作用 |
|------|------|
| 粒子荧光强度 0–100 | 同时调节粒子光晕形状、泛光（bloom）强度、白热光芯和星空背景。**0 = 不发光的普通实心小圆点**（类似原网页），此时泛光完全关闭 |
| 文字荧光强度 0–100 | 调节中空英文标题外层蓝色荧光的半径；0 时只剩描边 |
| 英文字体 | Oswald（默认）/ Bebas Neue / Orbitron / Michroma / Syncopate；标题字号按每种字体实测的字宽自动换算 |
| 字号 80–125% | 缩放英文标题与描述 |
| 背景音乐音量 / 交互音效音量 | 两路分开调节 |

设置保存在浏览器 localStorage 中（无法写入时仅本次访问有效）。

**字体说明**：参考站 usta.agency 在开发环境中被网络策略拦截，无法直接查看其 CSS。Awwwards 把该站收录在"使用 Oswald 字体的网站"列表中，因此默认采用 Oswald，这一点没有从源码证实。所有标题字体都先用 fontTools + skia-pathops 合并了重叠轮廓（`tools/make_fonts.py`），否则 `-webkit-text-stroke` 描边会露出字母内部的线条。

## 4. 配乐与音效（`src/audio.js`，全部由 Web Audio 实时合成）

**配乐**：失谐和弦铺底 + 次低音 drone + 星光钟声（长延迟与混响）。每页切换和声：首页利底亚调式，太阳页低沉，类地行星明亮，气态巨行星宏大，冰巨行星用四度叠置的冷色和声，冥王星只剩稀疏空五度，银河页收束。每页还有一个参考真实空间录音设计的声部：

- 太阳：低频轰鸣（参考日震学声化）+ 喷发噼啪声
- 地球："晨鸣"（磁层 chorus 波，听起来像鸟鸣的上行啁啾）
- 木星：哨声（whistler，闪电激发的下行音调）
- 土星：千米波辐射式的滑音 + 光环"冰晶瀑布"
- 金星 / 火星 / 海王星：浓重低沉 / 稀薄阵风 / 高速强风
- 水星：快速音阶（公转最快）；天王星、海王星：冰晶钟声；冥王星：稀疏的远处脉冲

**音效**（与动效一一对应）：滚动跃迁时的呼啸声（向外飞时上扬、返回时下沉，声像随之横移）；到达每个天体时的钟声和弦（离太阳越远音越低，太阳是一声锣）；点击冲击波（低频冲击 + 噪声 + 铃音，声像跟随点击位置）；光标"引力透镜"火花（越快越密）；拖拽自转的风声（音量和音高跟随转速）；按钮悬停 / 点击声；色态切换的上行 / 下行琶音；滑块刻度音（音高随数值变化）；标题霓虹灯通电时的电流嗡声（节奏与 CSS 闪烁动画一致）；设置面板开合声。

浏览器要求用户先交互才能出声：点"开启声音 · 出发"、右上角声音按钮，或第一次点击画面即可开启。

## 5. 交互

- **光标 = 引力透镜**：靠近光标的粒子按点质量透镜公式被推到爱因斯坦环上，环上粒子变亮。
- **点击**：放出一圈冲击波。
- **按住拖动**：让当前行星自转（松手后有惯性）；首页拖动会快进或倒放公转。手机上横向拖动旋转、纵向滑动翻页。
- 快捷键：<kbd>C</kbd> 切换配色 · <kbd>M</kbd> 声音 · <kbd>S</kbd> 设置 · <kbd>Esc</kbd> 关闭设置。

```
solar/
  build.mjs            打包成单文件（内嵌 three.js 与 base64 字体）
  fonts/*.woff2        去重叠、子集化后的英文标题字体

  tools/make_landmask.py  从 NOAA GLOBE 生成 1° 陆地掩膜
  src/
    main.js            滚动、布局、渲染循环、指针 / 拖拽 / 键盘、音频联动
    particles.js       粒子场与全部着色器（自转、光照、遮挡、阴影、环、月球、透镜、色态波）
    shapes/*.js        每个天体一个程序化建模文件（双色：multi + mono）
    ambient.js         深空背景（星云、阳光方向）与星空
    post.js            泛光 + 保色相色调映射（随荧光强度变化）
    audio.js           生成式配乐与音效
    settings.js        设置面板与持久化
    content.js         页面文案（中文说明 + 英文中空标题 / 描述）
    ui.js / body.html / styles.css
  dist/index.html      构建产物
```

## 7. 已知局限

- 只在无界面 Chromium（SwiftShader 软件渲染）里截图验证过画面，没有在真实 GPU 上测过帧率。低端手机可以用 `?n=` 降低粒子数，页面也会在前几秒掉帧时自动降低分辨率。
- 配乐只测了各场景的音量和是否报错，听感没有经过人耳验证。
- 天体大小与距离不按比例（每页的天体都放大到相近尺寸；首页轨道半径经过压缩）。
- 冥王星自 2006 年起属于矮行星，按需求作为"第九大行星"展示，页面文案已说明。
