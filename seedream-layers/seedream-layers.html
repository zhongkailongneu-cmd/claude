Seedream 5.0 Pro · 图层分离（Layer separation）

一张平面图进去，一叠可编辑图层出来

字节跳动的 Seedream 5.0 Pro（2026 年 7 月 8 日发布）有一个图层分离模式：给它一张做好的图，它返回一张底图，外加若干张透明 PNG 图层，每个元素一层，并且已经按从前到后的顺序排好（Atlas Cloud 的 API 页写的上限是 16 层，各平台不完全一致）。下面这台光具座把这件事做成了实物：每片玻璃装一层。

它是怎么拆图的

  1. 找出元素。不写提示词时，模型自己挑出每个主要元素；也可以点名（「鹦鹉」「标题文字」），或者框出一块区域来指定。
  2. 补画底图。元素被拿走以后，底图上它原来遮住的地方由模型补画出来，所以底图本身是一张完整的画。补出来的内容是模型推测的，不是原图里本来就有的像素。
  3. 排好顺序输出。每个元素是一张带透明通道的 PNG，按从前到后排好；按顺序叠回去，就得到原来那张图。

拆开以后能做什么

  1. 拆分：一张已经定稿的图，变回可以逐层修改的分层源文件。
  2. 视差：每层按离镜头的远近错开移动，就是 2.5D 视差动画和带景深的动态壁纸的做法。离镜头越近的层移动越多，倍数等于两层到镜头的距离之比。
  3. 换主体：只重画一层（鹦鹉换成巨嘴鸟），其他层的像素一点不变。
  4. 换配色：只改底图的配色（日落换成月夜），前景元素保持原样。
  5. 移标题：标题是单独的一层，可以随意移动或改字；它背后不用再补画，因为底图已经是完整的。

局限：毛发、半透明物体和互相交缠的元素，边缘可能拆得不干净；补画出来的背景是猜的，画面里本来看不到的信息无法真正还原。
