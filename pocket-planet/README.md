# Pocket Planet · 四季掌心星球

一颗可以在掌心里转动的低多边形（Low-Poly）小星球。表面按经度分成四个象限，春夏秋冬无缝过渡；一个小人可以在球面任意方向行走，相机平滑跟随，走进不同季节时会自动弹出当地地标卡片。

**直接打开 `dist/index.html`**（单文件，three.js 已内联，可离线双击运行）。
GitHub Pages 地址：https://zhongkailongneu-cmd.github.io/claude/pocket-planet/

## 操作

| 操作 | 键位 |
|---|---|
| 前进 / 后退 | `W` `S` 或 `↑` `↓` |
| 左转 / 右转 | `A` `D` 或 `←` `→` |
| 奔跑 / 跳跃 | `Shift` / `Space` |
| 环顾 / 缩放 | 鼠标拖拽 / 滚轮 |
| 跳转到某个季节 | 底部按钮，或 `1`–`4` |
| 全景俯瞰 | 底部「全景俯瞰」按钮，或 `V`；俯瞰时一按方向键就回到跟随视角 |
| 手机 | 左下摇杆行走，右下「跳」按钮跳跃，单指拖拽环顾 |

打开页面先显示全景俯瞰（四个象限一览），约 2.6 秒后镜头自动飞到小人身后。

## 四个季节

| 象限 | 经度中心 | 生态 | 地标 |
|---|---|---|---|
| 春 | 45°E | 粉色樱花树、野花、贯穿南北的小溪、朱红拱桥与石灯笼、飘落的花瓣 | 樱花溪桥 · 樱语林 · 清泉池 |
| 夏 | 135°E | 翠绿松林、灌木、两顶帐篷围着篝火（火光会闪）、萤火虫 | 萤火营地 · 松风湖 · 翠松林 |
| 秋 | 135°W | 金红枫树、蘑菇、木屋（窗户亮灯、烟囱冒烟）、草垛、南瓜车、篱笆南瓜田、落叶 | 丰收木屋 · 南瓜田 · 枫红山丘 |
| 冬 | 45°W | 雪山（峰顶插红旗）、雪松、雪屋、雪人、冰湖、飘雪、三条摇曳弯曲的极光带 | 极光雪峰 · 镜冰湖 · 雪屋 |
| 北极点 | — | 四季交汇处的路标，四块木牌分别指向四个季节 | 四季路标 |

## 实现要点

- **地形**：细分 30 次的二十面体（19,220 个三角面），顶点按高度函数外推。高度 = 全局噪声 + 各季节特有起伏（秋季丘陵、冬季山脊噪声）+ 地标处理（雪峰隆起、营地/木屋整平、湖盆下凹、小溪河道下切）。
- **无缝过渡**：每个点按经度算四个季节权重，过渡带宽 ±15°，分界经度再叠加低频噪声，所以季节之间的边界是弯曲自然的。地面颜色、水面颜色（冬季变冰）、植被种类都按这组权重混合或抽样。
- **球面行走**：小人的"上"始终是球心指向它的法线方向（径向重力）。移动时把速度向量沿切平面推进，再用四元数把朝向和速度"平移"到新的位置，避免在球面上越走越歪。脚下高度通过对真实三角面做射线求交得到（按 2.5° 经纬网格分桶加速），所以脚始终踩在低多边形面上。
- **地面状态**：踩上桥面会沿拱形抬高；走进溪水会半身没入、减速并出现水波圈；冰湖表面打滑（加速度很低，松开按键还会滑一段）。
- **相机**：跟随模式下相机在小人身后上方，位置按"方向球面插值 + 半径线性插值"平滑过渡，所以从俯瞰切回跟随、或跨半个星球跳转时不会穿过星球。主光源始终从观察者肩膀方向照来，阴影朝远处投下。
- **害羞的树**：挡在相机和小人之间的树会缩进地里，视线畅通后再弹回来。
- **粒子**：花瓣、萤火虫、落叶、雪花各一套 GPU 粒子，运动全部在顶点着色器里完成；落体方向指向球心。溪水上的光点由 CPU 沿河道推进。
- **极光**：三条 160×18 段的带状网格，在顶点着色器中沿球面弯曲并随时间左右摆动，片元着色器做竖向射线纹理和薄荷绿→青→淡紫的渐变，加法混合。
- **地标卡片**：每 0.15 秒判断小人所在季节（与地面配色用的是同一套权重），取同季节中最近的地标；地标变化时卡片弹出，季节变化时屏幕中央出现季节横幅。卡片还显示经纬度和到地标的大致步数。

## 配色

- 界面（卡片、底部按钮栏、操作说明、太空背景、水面、冰面、雪地阴影、小人背带裤）使用 Loyel 渐变蓝色板（#F4F7FB → #263B54）。
- 星球上的季节色（樱花粉、松绿、枫红、篝火橙、极光绿紫）按语义需要使用，不属于数据可视化配色。

## 开发

```bash
npm install                  # 在仓库根目录
npm run build:planet         # 生成 pocket-planet/dist/index.html 和 docs/pocket-planet/index.html
npm run dev:planet           # 监听修改并在 http://localhost:8001 预览
```

```
pocket-planet/
  build.mjs          esbuild 打包；输出离线单文件、Pages 副本和 claude.ai 预览版
  src/world.js       季节象限、高度函数、小溪与桥、地标与出生点
  src/planet.js      地形网格与配色、水面（含冰面）
  src/surface.js     精确地面高度（射线 × 三角面，经纬网格分桶）
  src/props.js       树木花草（实例化渲染）与各季节地标建模、炊烟篝火动画、害羞的树
  src/effects.js     花瓣/萤火虫/落叶/飘雪粒子、溪水光点、极光、星空、月亮
  src/character.js   小人建模与走路/跳跃动画
  src/ui.js          地标卡片、季节横幅、底部按钮栏、触屏摇杆
  src/main.js        渲染器、灯光、行走物理、相机、主循环
```

测试钩子：`window.__planet.hop(i)` 跳到第 i 个季节，`window.__planet.overview(true)` 切换俯瞰，`window.__planet.advance(秒)` 按固定步长推进模拟（用于无界面截图），`window.__planet.state` 返回当前位置、季节和地标。

## 已知局限

- 只在 SwiftShader 软件渲染下截图验证过，没有在真实 GPU 或真机上测帧率。
- 树和石头会挡路（有碰撞），但帐篷、木屋等是圆形碰撞体，贴着墙走时边缘略不精确。
- 小溪可以涉水穿过，桥下水中行走时头部可能与桥面略有穿插。
