【核心思路】仓库里已有一套我上次做的「Luminous Deep」粒子引擎（Three.js + 自定义着色器 + Web Audio）。这次新建一个独立的 solar/ 项目来复用这套架构，不覆盖原来的海洋站。

参考站说明：usta.agency 在本环境被网络策略屏蔽，无法直接查看源码。Awwwards 把该站收录在「使用 Oswald 字体的网站」列表里，所以标题与英文描述用 Oswald（尚未从源码证实，设置面板里可以换字体）。

## 实现过程中的关键环节（摘要）

【说明】以下为执行过程的摘要，由工具调用记录整理，不是逐字原文。

- 参考站调研：直连 usta.agency、Wayback Machine、Awwwards 均被网络策略拒绝（403）；通过搜索确认该站为 Awwwards Honorable Mention（2024-04-05，作者 gianluca-lomarco），收录在 Oswald 字体列表。
- 字体：从 @fontsource 取得 Oswald、Bebas Neue、Orbitron、Michroma、Syncopate，用 fontTools + skia-pathops 合并轮廓重叠并子集化，每个约 5–8 KB，base64 内嵌。
- 地球陆地：取 NOAA GLOBE 1 km 掩膜（PyPI global-land-mask），降采样为 360×180 的 1° 位图（陆地占比 33.7%）。
- 建模：12 个程序化形状文件，每个粒子带 multi / mono 两套颜色；Node 冒烟测试 12 个形状均填满 60,000 粒子、无 NaN。
- 渲染：自定义顶点着色器处理自转、日照明暗、被行星遮挡与阴影、土星环开普勒公转、月球轨道、引力透镜光标、点击冲击波、色态扫描波；后期泛光随荧光强度变化，强度为 0 时关闭。
- 截图迭代：多轮无界面 Chromium 截图后调整亮度增益、粒子大小、太阳过曝、地球对比度、冥王星心形对比度，并修正手机端亮度。
- 音频测量：12 个场景均有声音；多个界面音效偏轻，已调大。
- 交互测试：点击、拖拽、C / S / Esc 快捷键、导航点、设置滑块、localStorage 持久化均通过，控制台无报错。
- 交付：单文件构建 666 KB；提交 0f8903f 并推送；预览以 claude.ai 页面形式发布。

# 第二轮 · 橙色荧光字体选项

## 用户提问（原文）

将蓝色荧光字体增加一种接近太阳颜色的橙色荧光作为英文字体颜色的可切换选项

## Claude 回复（原文）

橙色荧光已经加好了：英文字体颜色现在可以在蓝色和接近太阳颜色的橙色之间切换。预览链接（同一个地址，已是第 3 版）：https://claude.ai/artifact/YVmHTCRUZmxzTyfy21XKeP

### 怎么切换

- 右上角「设置」→「英文字体颜色」，选「蓝色荧光」（默认）或「橙色荧光」。
- 也可以直接按 T 键来回切换。
- 选择会和其他设置一起保存，刷新页面后仍然有效；「恢复默认」会回到蓝色。

### 橙色的配色

颜色都取自页面里太阳本身的色系：

| 层次 | 蓝色（原有） | 橙色（新增） |
|---|---|---|
| 灯管（描边） | #E6FAFF 冷白 | #FFF3E4 暖白 |
| 荧光光晕 | #38C8FF | #FF9F3A 琥珀橙 |
| 最外圈光晕 | #376392 | #B8360A 深火焰色 |

### 哪些地方会变色

- 跟着变：所有中空英文大标题和英文描述句、加载画面的标题、左上角品牌字、设置里的字体预览，以及标题下方的霓虹按钮（如「开启声音 · 出发」）。
- 保持蓝色：设置面板、滑块、开关这些界面控件。这是我自己定的范围，因为你提的是"英文字体颜色"。如果想让整套界面也一起变橙，告诉我即可。
- 切换时，当前页标题会重新"通电"闪烁一次，并伴随霓虹电流声。

### 审查后修正的问题

加完之后我用三个角度审查了改动，每个问题再由独立复核确认，确认了两个问题，都已修复：

- 在设置里点颜色选项时，点击音会叠加播放两次，比其他按钮响一倍。现在只响一次。
- 设置面板里的「恢复默认」按钮在橙色模式下悬停会发出橙光。现在保持蓝色。

另外顺手改进了一点：把「文字荧光强度」调到 0 时，原来两种颜色都只剩接近白色的描边，几乎看不出区别。现在描边本身会随荧光减弱而偏向所选颜色，荧光为 0 时就是清晰的橙色或蓝色轮廓。

在无界面浏览器里截图检查过：首页、太阳、地球、单色模式下的土星（橙字配蓝色行星）、设置面板和手机布局都正常，控制台没有报错。改动已推送到 claude/confident-newton-eifqx8 分支，docs/solar/ 也同步更新了。
