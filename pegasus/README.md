# Pegasus · 光纤流动滚动网页

复刻自一段 25 秒的网页录屏（"Pegasus" 区块链数据基础设施官网）：一束束发光光纤随滚动不断变形，最后升起一块 3D 仪表盘。在原版的基础上增加了 **三套可切换色系** 和 **程序合成的 BGM**。

**直接打开 `dist/index.html`**：它是单文件（three.js、CSS、Inter Tight 字体全部内嵌），双击即可离线运行。
GitHub Pages 路径：`docs/pegasus/index.html`（由 `dist/index.html` 复制而来）。

```bash
cd pegasus
npm install
npm run build     # 生成 dist/index.html
npm run dev       # 监听修改并在 http://localhost:8001 预览
```

### 渲染引擎（`src/fibers.js`）

一个 GPU "光纤场"：900 根丝束（手机 520）× 96 段，画成屏幕空间的带状网格，加法混合。**每个场景都是顶点着色器里的一条公式**，丝束只带一个随机 id，所以能在扇形、漏斗、光束、双曲面、管道、虹膜之间变形：

- 场景 0–3：三次贝塞尔脊线 + 带"腰部"的宽度曲线（`conePar()` 里每个场景一组参数）
- 场景 4：直纹面 `A(φ) → B(φ+tw)`，绕 x 轴倾斜
- 场景 5：摆线脊线 + 螺旋截面，按法线与光源的夹角做高光
- 场景 6：径向丝束，带随机弯曲与穹顶深度
- 场景切换：每根丝带 0–0.5 的随机延迟，过渡中段向随机方向旋涡散开
- 后期（`src/post.js`）：Bloom → 按最亮通道压缩（保色相，密集处白热）→ 与主题背景做 screen 混合 → 暗角、色散、颗粒

## 三套色系（`src/themes.js`）

| 色系 | 光纤 `c1 / c2 / c3 / hot` | 背景 |
|---|---|---|
| **Pegasus Violet**（视频原版） | `#A98DFF` `#5A6CFF` `#E27FE6` `#F6F1FF` | 近黑 |
| **Loyel Gradient Blue** | `#6C9AC4`(50) `#376392`(70) `#9FBDDA`(40) `#F4F7FB`(10) | `#2B4868`(90) → `#263B54`(100) |
| **Aurora Green 极光绿** | `#2DF5A6` `#18C8D8` `#9B8CFF`（淡紫边缘）`#E6FFF4` | 深青黑 |

- Loyel 主题 **只使用官方十档色值**（`#F4F7FB … #263B54`），仪表盘的面板、柱状图、徽标全部取自这十档；文字为 `#FFFFFF` / `#CCDBEB` / `#9FBDDA`。
- 极光绿的十档色阶（`AURORA`，`themes.js`）是为本项目新定义的，不是既有规范，想换色只改 `THEMES.aurora` 一处。
- 切换时 WebGL 颜色、背景、泛光强度、DOM 的 CSS 变量与 BGM 的调性一起过渡。选择会保存在 `localStorage`。

## BGM（`src/audio.js`）

全部用 Web Audio **实时合成**，没有音频文件，也就没有版权问题；永远不会精确循环。

分析了视频自带音轨：能量集中在 35–65 Hz 的次低频，4 kHz 以上有一层"空气感"，节奏很慢（约 1.4 s 一次脉动）。BGM 照这个配方做，并让它对页面作出反应：

- 次低频 drone + 慢速"心跳"脉冲（随滚动深入逐渐加强）
- 失谐锯齿波 pad，每 16 秒换一个和弦，滚动越深滤波器越开
- 玻璃质感的钟音，经立体声延迟和 4.8 s 混响
- 高频空气噪声
- 滚动速度驱动的 whoosh；每次新场景锁定时一记轻微的 boom + 钟音
- 低频瞬态驱动光纤的辉光（`uBeat`）

每个主题有各自的调性：Violet = D 小调（带升 4 级色彩）、Loyel = F 利底亚、Aurora = E 利底亚；切换主题会在新调里响一小串钟音。

浏览器不允许自动播放，所以首屏有 "Enter with sound / Continue without sound"。左下角的 SOUND 按钮或键盘 `M` 可随时开关。

## 操作

| | |
|---|---|
| 滚动 / 触摸滑动 | 推进场景 |
| `1` `2` `3` | 切换 Violet / Loyel / Aurora |
| `M` | 开关 BGM |
| 鼠标移动 | 丝束被轻轻拨开，相机轻微视差 |

调试参数：`?p=2.5` 固定在某个进度并跳过入场；`?theme=aurora`；`?n=600` 改丝束数量；`?g=1.5` 亮度倍数；`?b=0.6` 泛光强度。

## 文件

```
src/main.js     滚动进度、场景状态机、文字/仪表盘/主题/加载页的控制、渲染循环
src/fibers.js   丝束与尘埃/散景/节点的着色器与几何
src/post.js     Bloom 与最终合成
src/themes.js   三套色系（WebGL 颜色 + CSS 变量）
src/audio.js    BGM 合成器（可注入 AudioContext，支持离线渲染测试）
src/ui.js       标题解扰、数字滚动、图表/卡片、主题切换器
src/guard.js    无 WebGL2 时的提示
src/body.html · styles.css
build.mjs       esbuild 打包 + 字体 base64 内嵌 → dist/index.html
```

## 说明与局限

- 品牌名 "Pegasus" 和仪表盘里的数据、文案都来自视频里的演示站，是虚构内容。
- 参考站本身无法访问，场景的形状是对着视频逐帧复刻的近似，不是原站源码。
- 验证方式：在无头 Chromium（软件渲染）里对各个进度、三套色系、桌面与手机尺寸截图比对；BGM 在离线音频上下文里渲染后检查峰值（0.65，无削波）和频谱（20–120 Hz 与视频音轨基本重合）。**没有在真实 GPU 上测过帧率，也没有人耳试听**，两者请在你的设备上确认。每 70 帧统计一次平均帧时间，超过 28 ms 就自动降低渲染像素比（最低到 1）。
