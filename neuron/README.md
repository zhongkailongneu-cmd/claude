# Synapse · 从一个神经元到神经网络

把上一版的"光纤"换成了**神经元**：一个细胞伸出树突、放出轴突，轴突沿着化学线索延伸，邻近的神经元相继萌发，轴突末梢与树突接触形成突触，最后连成整张网络，同步放电。三套色系不变，BGM 换成了热血、燃的战斗番风格，神经元会踩着鼓点放电。

**直接打开 `dist/index.html`**：单文件（three.js、CSS、Inter Tight 字体全部内嵌），双击即可离线运行。
GitHub Pages 路径：`docs/neuron/index.html`（由 `dist/index.html` 复制而来）。

```bash
cd neuron
npm install
npm run build     # 生成 dist/index.html
npm run dev       # 监听修改并在 http://localhost:8001 预览
```

## 故事线（滚动驱动）

| 阶段 `p` | 画面 | 实现 |
|---|---|---|
| 入场 | 一个神经元从胞体长出树突，轴突向右延伸；背景里有几个景深中的邻居 | 生长时钟 `S` 从 -1 走到 0，英雄神经元自己长出来 |
| 0 · **神经元** | 英雄神经元静静发光 | 每隔一小节放电一次：胞体闪光、树突发亮、脉冲沿轴突前进 |
| 1 · **延伸** | 镜头跟着轴突尖端的**生长锥**前进，靠近第二个神经元，它的树突正伸过来 | 镜头在 `heroTip(S)`（英雄轴突生长前沿）上滑动；生长前沿处有高亮 |
| 2 · **扩展** | 镜头拉远，神经元一圈圈向外萌发，树突不断分叉 | 每个神经元的出生时间随到英雄的距离增加，像涟漪向外扩散 |
| 3 · **连接** | 镜头推到一个正在形成的突触：轴突末梢触到树突，亮点炸开一圈光环 | 突触形成时刻 = max(轴突尖端到达, 靶树突长出)；形成瞬间闪光 |
| 4 · **网络** | 镜头拉到全景：约 130 个神经元、约 800 个突触接触点织成网络，放电在其中接力 | 级联沿真实的轴突连接传播，延迟 = 轴突长度 / 速度 + 突触延迟 |
| 5 · **点燃** | 同步放电席卷全网，每一拍都有多颗种子细胞同时点火，镜头缓缓环绕 | 级联频率随进度加密到每拍一次；`heat` 提升辉光；画面随鼓点轻微"顶一下" |
| 5.8–8 | 神经活动控制台（示例数据）倾斜升起，网络在背后继续放电；结尾回到全网和行动按钮 | 同上一版的 3D 倾斜面板 + 数字滚动 |

### 神经元是真的"长"出来的（`src/neurons.js` + `src/field.js`）

- **形态生成**：固定随机种子。每个神经元有一个胞体、4–8 条树突（递归二分叉，带侧枝和树突棘）、一条轴突。轴突是带轻微摆动的贝塞尔曲线，沿途分出侧支，末端分成 1–3 条末梢，终止在靶细胞树突尖端的突触小体上。130 个神经元约 5.7 万个折点、810 个突触接触点，生成约 200 ms。
- **GPU 生长**：每个顶点带一个 `aGrow`，表示该神经元生长进度走到多少时这个点才出现；树突占 0–30%，轴突占 20–100%（所以先长树突、再延伸轴突）。着色器按 `f = (S − birth) / span` 揭示分支，并在生长前沿加亮；生长锥是单独的发光点。
- **放电级联（`src/activity.js`）**：从种子细胞出发做最短路径搜索，沿轴突连接传播；每个神经元的放电时间写入一张数据纹理（每个神经元 8 个槽位），着色器据此画胞体闪光、树突回传发光、沿轴突奔跑的动作电位脉冲，以及脉冲到达时突触小体的闪烁。
- **渲染**：丝束画成屏幕空间带状网格，胞体/生长锥/突触小体/树突棘/漂浮微粒（神经递质）是点精灵；加法混合 + Bloom + 保色相的色调映射；远处按深度衰减。

## 三套色系（`src/themes.js`）

| 色系 | 树突 | 轴突 | 突触 | 高光 | 背景 |
|---|---|---|---|---|---|
| **Pegasus Violet**（原色系） | `#A98DFF` | `#8EA2FF` | `#FF8AD8` | `#F6F1FF` | 近黑 |
| **Loyel Gradient Blue** | `#6C9AC4` (50) | `#9FBDDA` (40) | `#CCDBEB` (30) | `#F4F7FB` (10) | `#2B4868` (90) → `#263B54` (100) |
| **Aurora Green 极光绿** | `#2DF5A6` | `#20D6E6` | `#B2A4FF` | `#E6FFF4` | 深青黑 |

Loyel 主题只用官方十档色值（包括控制台的面板、柱状图、徽标）。极光绿是我为这个项目定义的，想换色只改 `themes.js` 里 `aurora` 一处。主题切换会同时过渡神经元颜色、背景、DOM 的 CSS 变量，以及 BGM 的调性。

## BGM「Ignite」（`src/audio.js`）

Web Audio 实时合成，没有音频文件，没有版权问题。

- **风格**：热血战斗番式。小调、八小节循环 `i – VI – III – VII | i – VI – VII – V`（原调 A 小调：Am F C G | Am F G E），八分音符驱动的锯齿波贝斯、失真强力和弦"砍"、英雄主旋律（长–短–短的号角式节奏）、太鼓 don/ka、军鼓与鼓组填充、镲片、上升音效与重低音撞击。贝斯、和弦、琶音会随底鼓"侧链抽吸"。
- **每套色系一个调性和速度**：Violet = A 小调 150 BPM，Loyel = E 小调 144 BPM，Aurora = D 小调 156 BPM。切换主题会在新调里响一小段英雄琶音。
- **随故事逐层加入**（由滚动进度算出一个"能量值"）：

| 能量 | 加入的层 |
|---|---|
| 入场 – 神经元 | 铺底和弦 + 八分琶音 + 心跳般的太鼓 |
| 延伸 | 底鼓、踩镲、贝斯长音 |
| 扩展 – 连接 | 军鼓、八分贝斯、失真和弦"砍"、十六分琶音 |
| 网络 | 主旋律、填充鼓点、镲片 |
| 点燃 | 主旋律加高八度、持续和弦、每小节镲片；进入前有上升音效 |
| 控制台 | 回落到较低能量，仍保持驱动感 |

- **踩点放电**：乐谱每个十六分音符发出回调，主程序在四分音符上让画面"顶一下"并按进度触发放电级联；关闭声音时用 140 BPM 的备用节拍器代替。
- 浏览器不允许自动播放，所以首屏有 "Enter with sound / Continue without sound"。左下角 SOUND 按钮或键盘 `M` 可随时开关。

## 操作

| | |
|---|---|
| 滚动 / 触摸滑动 | 推进故事 |
| `1` `2` `3` | 切换 Violet / Loyel / Aurora |
| `M` | 开关 BGM |
| 鼠标移动 | 相机轻微视差 |

调试参数：`?p=2.5` 固定在某个进度并跳过入场；`?theme=aurora`；`?n=80` 改神经元数量；`?g=1.5` 亮度倍数；`?b=0.6` 泛光强度；`?fire` 持续触发放电；`?dbgT=1.2` 冻结时钟在"放电开始后 1.2 秒"（截图用）。

## 文件

```
src/main.js      滚动进度、生长时钟、节拍→放电、文字/控制台/主题/加载页、渲染循环
src/neurons.js   神经元网络的程序化生成（树突、轴突、末梢、连接图、数据纹理）
src/field.js     着色器（带状分支、点精灵、微粒）、相机路径
src/activity.js  放电级联（最短路径传播，写入数据纹理）
src/audio.js     BGM 合成器与步进音序器（可注入 AudioContext，支持离线渲染测试）
src/post.js      Bloom 与最终合成（含鼓点"顶一下"）
src/themes.js · ui.js · guard.js · body.html · styles.css
build.mjs        esbuild 打包 + 字体内嵌 → dist/index.html
```

## 说明与局限

- 神经元形态是程序化生成的示意，不是真实重建的形态学数据；连接图也不对应任何真实脑区。控制台里的数字和脑区卡片是示例数据，页面上已标注 "sample data"。
- 验证方式：无头 Chromium（软件渲染）里对各进度、三套色系、桌面与手机尺寸截图检查；放电级联用 `?dbgT` 冻结时钟逐帧检查；BGM 在离线音频上下文里渲染后检测：节拍检测恰为 150 BPM，满能量峰值 0.75（有软削波保护，不会爆音），平均响度约 -13.4 dBFS，开场层约 -21.8 dBFS。**没有在真实显卡上测过帧率，也没有人耳试听**，音量、混音平衡和旋律好不好听请在你的设备上确认。每 70 帧统计一次平均帧时间，超过 28 ms 会自动降低渲染像素比。
