# Island Jelly · 海岛果冻微缩展台

一个可以戳、可以摇的方形截面果冻海微缩展台。Three.js r169 + 自定义 GLSL，单个 HTML 文件，无构建依赖。

**在线页面（GitHub Pages）：** https://zhongkailongneu-cmd.github.io/claude/island-jelly/

## 文件

```
island-jelly/island-jelly.html   源文件（claude.ai artifact 页面片段：样式 + 结构 + 模块脚本）
scripts/build-island-jelly.mjs   把片段包成完整 HTML，写到 docs/island-jelly/index.html
docs/island-jelly/index.html     GitHub Pages 发布的页面（three.js 从 jsDelivr 加载）
```

修改源文件后运行 `npm run build:jelly`（或 `node scripts/build-island-jelly.mjs`）。

## 交互

| 操作 | 效果 |
|------|------|
| 单击 / 按住果冻 | 手指压出高斯形凹陷，松开后回弹并激起波纹，整块上下 Q 弹 |
| 从果冻上拖拽 | 抓住果冻顶部剪切拉动，松手后整块弹簧摆回；摆动的加速度会激起晃荡波 |
| 拖拽空白 / 滚轮 | 旋转视角 / 缩放 |
| 点岛或椰子树 | 摇树，掉下一颗椰子（落在沙滩上会顺坡滚进果冻） |
| 点螃蟹 / 椰子 | 让它跳起再落回果冻 |
| 键盘（画布获得焦点） | 空格 = 随机戳一下，方向键 = 朝该方向摇 |

右侧面板：投放招潮蟹 / 椰子标本（最多 10 件），切换口味（泻湖蓝 / 覆盆子粉 / 青柠绿），调节硬度、波浪阻尼、潮汐水位，查看波速、整块摆动频率、最大起伏与表面能量曲线。

## 实现要点

**渲染（每帧三次绘制）**
1. 不透明场景（底座、岛、椰子树、海草、气泡、标本）渲染到离屏目标，带深度纹理。
2. 同一场景渲染到屏幕。
3. 果冻网格用自定义着色器绘制在上面：
   - 折射：按折射率 1.34 求折射方向，与果冻包围盒求出射距离，把出射点投影回屏幕采样离屏纹理；红、蓝通道偏移略不同，形成轻微色散。采样点若在果冻前方（例如露出水面的螃蟹），退回到不偏移的采样。
   - 吸收：厚度取「盒子出射距离」与「深度纹理里背后物体的距离」中较小者，按 Beer–Lambert 定律 `exp(-σ·d)` 着色；σ 由口味颜色换算。
   - 次表面散射近似：包裹漫反射 + 背光透射项，乘以随厚度增加的散射量。
   - 反射：Schlick 菲涅耳 + 程序化摄影棚环境（天光、两块固定柔光箱、一块随视角移动、始终被平静水面映出的主柔光箱，所以凹陷和波纹会把它的边缘弄弯）。
   - 顶面边缘做了半径 0.11 的圆角；岛岸附近加泡沫带。
4. 水底和岛的水下部分有焦散：两层动画 Voronoi 边缘，再按水面梯度偏移、按水面拉普拉斯（聚焦）加亮。

**物理（120 Hz 定步长）**
- 水面：128 × 128 网格二维波动方程，`v += c²·∇²h − k·h`，再乘 `(1 − 阻尼)`。岛露出水面的格子是固定边界，浅水处波速按水深降低。高度场每帧上传为 RG32F 纹理（R = 波高，G = 岛高），顶点和片元着色器都从中采样。
- 整块果冻：顶面剪切 `s` 和竖向压扁 `q` 各是一个二阶弹簧阻尼系统；顶点按高度 `w(t) = t²(1.5 − 0.5t)` 叠加剪切，底部不动。海草、气泡、漂浮物用同一变形函数（GLSL 与 JS 各一份）。
- 标本：下落 → 撞击（向水面注入冲量、激起整块压扁）→ 在果冻上做竖向弹簧回弹，水平方向顺坡下滑、受整块加速度拖拽；螃蟹会横着走，手指靠近时举钳逃开；椰子按速度滚动。

**参数映射**
- 硬度 0–100 → 波速系数 0.10–0.42、回复力、凹陷深度 0.21–0.075、整块摆动 1.0–3.3 Hz；面板显示的 kPa 按明胶类凝胶 1–16 kPa 粗略换算，只用于对比手感。
- 阻尼 0–100 → 每步衰减 0.0012–0.05、阻尼比 ζ 0.03–0.42。
- 潮汐 0–100 → 水面高度 0.06–0.48（水深 3.4–5.9 cm），岛的露出面积和固定边界随之变化。

## 配色

界面和图表使用 Loyel 渐变蓝色板（#F4F7FB → #263B54）；泻湖蓝口味的吸收系数也取自色板中的 #9FBDDA。覆盆子粉、青柠绿、沙土、岩石、椰子树、螃蟹使用各自的语义颜色。
