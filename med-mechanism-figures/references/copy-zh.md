# 中文文案模板

文案也是设计的一部分。写法要像一位懂行的老师在讲话：句子短、主动语态、不卖弄。全文用中文；英文术语第一次出现时写成「中文（English）」，之后只用中文或通用缩写。

## 页面结构与模板

```
小标题（kicker）  {领域} · {机制名}（{English name}）
大标题（h1）      一句话写出问题或结论，不超过 20 个字
导语              2–3 句：现象是什么 → 用什么机器来比喻 → 读者该盯着看什么

[卡片]
  左上   Fig {n}
  右上   {图名，不超过 8 个字}
  左下   {交互提示}，例：拖动调节浓度 · 按键 1–4
  右下   {实时读数}，格式：{量} {值}{单位}{出处号} · {量} {值}{单位}
[场景按钮]  {序号} {中文名} {English}
[图例]  高亮：读者要盯着看的那个部件 / 实体：…… / 线：……
[图注]  一段话，说明这台机器各部分对应什么，以及时间是否做了缩放

## 它是怎么工作的        3–5 步，每步一句粗体小结 + 一两句解释
## 比喻的边界            至少 2 条，句式：「图中……；真实情况是……」
## 证据与出处            由 sourcesHtml() 生成
免责声明（涉及临床时）    本图为机制示意，不能替代个体化诊疗；剂量和用法以药品说明书和临床指南为准。
```

## 写作规则

- **读数**：使用等宽字体，量和值之间空一格，单位紧跟数值；多个量之间用「 · 」分隔。示意值写「（示意）」。
  例：`释放 2 个量子 · 均值 m 1.8¹ · 失败率 6%（示意）`
- **数字与单位**：数字和单位之间加空格（`6.0 h`、`18 mg/L`）；百分号、度数和上标不加空格。浓度、时间、电压等使用国际单位或临床惯用单位。
- **标点**：正文用中文标点；读数和公式里用半角符号。
- **术语**：同一个概念全文只用一种叫法，例如不要一会儿写「清除率」、一会儿写「消除率」。
- **不要**：「值得注意的是」「众所周知」这类空话；「不是……而是……」这种为了制造反差的句式；感叹号；表情符号当作标题标记。

## 填好的示例：血脑屏障过滤闸

```
小标题   药代动力学 · 血脑屏障（Blood–brain barrier）
大标题   为什么大多数药物进不了脑
导语     脑内毛细血管的内皮细胞连接得极其紧密，还装有把药物推回血液的外排泵。下面这道过滤闸把血脑屏障做成了实物：看清哪些分子穿了过去，哪些被泵推了回来。

左上     Fig 1
右上     血脑屏障过滤闸
左下     点击分子换一种 · 按键 1–4
右下     通过 2/100 · Kp,uu 0.1（示意）· P-gp 外排开启

场景按钮  1 被动扩散 Passive   2 外排泵 P-gp   3 抑制外排 Inhibit   4 专用转门 Transporters

图注     闸板代表内皮细胞膜，接缝代表紧密连接，右侧的泵代表 P-糖蛋白（P-gp），它消耗 ATP，把底物推回血液侧；下方的转门代表 GLUT1 等摄取转运体。动画速度已经放大，真实的转运发生在毫秒到分钟的时间尺度上。

它是怎么工作的
1. 紧密连接把缝隙封死。分子不能从细胞之间钻过去，只能穿过细胞本身。
2. 脂溶的小分子能溶进膜里。分子越小、越脂溶、氢键越少，越容易通过。
3. 外排泵把一部分推回去。P-gp 的底物即使进了膜，也会被泵回血液侧。¹
4. 专用转门放行必需的营养。葡萄糖、氨基酸这类分子靠转运体进入。

比喻的边界
- 图中的闸门像一张筛子；真实的血脑屏障是由内皮细胞、周细胞、星形胶质细胞足突，以及多种转运体和代谢酶共同组成的一个单元。²
- 图中只画了一台泵；真实情况下 P-gp 之外还有 BCRP 等多种外排转运体。
- 「98% 以上的小分子进不了脑」是综述给出的估计³，不同药物之间差别很大。

证据与出处
1. Schinkel AH 等（1994）· Cell 77(4):491–502 · 小鼠 · C
2. Abbott NJ 等（2010）· Neurobiol Dis 37(1):13–25 · D
3. Pardridge WM（2005）· NeuroRx 2(1):3–14 · D
示意值：Kp,uu 0.1；通过数 2/100
```
