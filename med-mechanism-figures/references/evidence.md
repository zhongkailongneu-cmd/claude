# 读数与出处

读数和刻度会让读者以为「这是测出来的」，所以每一个数字都要能追溯到出处。

## 规则

1. **先登记，再显示。** 页面上的每一个数字（读数、刻度、图注、正文）都对应 `defineParams` 里的一项，包括数值、单位、出处 ID 和证据级别。实时读数也一样：读数是由已登记的参数，按已注明出处的模型算出来的。
2. **证据级别**：

   | 级别 | 含义 | 页面上怎么写 |
   |---|---|---|
   | A | 指南、系统综述或 RCT | 直接引用 |
   | B | 单项临床研究或人体测量 | 写明人群 |
   | C | 动物或体外研究 | 写明物种或体系，例如「小鼠」「蛙神经肌肉接头」 |
   | D | 教科书、综述或共识 | 直接引用；有原始研究时优先引原始研究 |
   | S | 示意值：为了画面而设，不是实测 | 数字旁标「示意」，出处列表里单列 |

3. **出处要核对过。** 作者、年份、期刊、卷期页码，以及 DOI 或 PMID，都用检索工具核对：PubMed、Amass、Consensus 等连接器可用时优先用，否则用网页搜索。不要凭记忆写卷期页码。查不到原文的，标【待核】，并在交付说明里列出来。
4. **出处号。** 读数和图注里的数字后面加上标出处号，由 `mark(sourceId)` 生成（¹²³…，按出处列表的顺序编号）。示意值写「（示意）」，不加出处号。
5. **免责声明。** 涉及剂量、血药浓度、治疗窗、疗效数据时，页面底部加上：「本图为机制示意，不能替代个体化诊疗；剂量和用法以药品说明书和临床指南为准。」
6. **动物或体外的数据不写成人体的结论。** 例如 mdr1a 敲除小鼠的实验结果，只能说明「P-gp 在小鼠血脑屏障外排中起作用」。

## 引用格式

`作者（年份）· 期刊 卷(期):起止页 · DOI 或 PMID · 一句话：支持图中的哪个数字或哪句话 · 证据级别`

例：`del Castillo J, Katz B（1954）· J Physiol 124(3):560–573 · 终板电位的量子成分，支持二项分布模型 · C`

## 用 `assets/evidence.mjs` 登记和检查

```js
const { defineSources, defineParams, mark, auditOrExit, sourcesHtml, EVIDENCE_CSS } = await import(pathToFileURL(join(ASSETS, "evidence.mjs")).href);

const SOURCES = defineSources([
  { id: "katz54", cite: "del Castillo J, Katz B（1954）· J Physiol 124(3):560–573", level: "C", supports: "二项分布释放模型" },
  { id: "branco09", cite: "Branco T, Staras K（2009）· Nat Rev Neurosci 10(5):373–383", level: "D", supports: "释放概率在突触间差异很大" },
]);
const PARAMS = defineParams([
  { id: "n", label: "释放位点数", value: 10, unit: "个", level: "S" },
  { id: "p", label: "释放概率", value: 0.2, unit: "—", level: "S", note: "中枢突触的 p 范围很宽，此处取示意值", source: "branco09" },
]);
// 读数里：`均值 m ${(n*p).toFixed(1)}${mark("katz54", SOURCES)}`
auditOrExit(PARAMS, SOURCES, { texts: [caption, intro] });   // 不通过就以退出码 1 结束构建
const sourcesSection = sourcesHtml(PARAMS, SOURCES);        // 页面底部的「证据与出处」
```

`auditOrExit` 检查的内容：
- 每个参数都有单位和证据级别，级别必须是 A、B、C、D、S 之一；
- 不是示意值（S）的参数必须有出处，并且出处 ID 存在；
- 每个出处至少被一个参数或读数用到，没用到的会给出警告；
- 标了【待核】的出处会被列出来提醒；
- `texts` 里的数字后面没有出处号，也没有标「示意」的，会被列为警告（这是启发式检查，年份、图号、步骤编号会被忽略）。

## 人工检查清单（交付前逐条核对）

- 页面上的每一个数字都能在登记表里找到。
- 每个出处都核对过卷期页码，或者已标【待核】。
- 证据级别标对了；动物或体外数据没有写成人体结论。
- 示意值在页面上标了「示意」，出处列表里单独列出。
- 读数的单位与出处一致，没有换算错误。
- 有临床数值的页面有免责声明。
- 交付说明里列出了所有【待核】的出处和所有示意值，提醒用户需要时换成真实数据。
